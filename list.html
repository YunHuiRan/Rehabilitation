✅ 待办事项应用

原生 JS
增删改 · 完成标记 · 分类标签 · localStorage 持久化
🎯 核心知识点:DOM 操作 / 事件监听 / 数据持久化
📋 功能要求
  • 输入框添加任务,支持回车与按钮提交,空内容拦截
  • 任务支持编辑 / 删除 / 标记完成与未完成
  • 任务可设置分类标签(预设 + 自定义)与优先级(高 / 中 / 低)
  • 筛选切换:全部 / 进行中 / 已完成,并显示剩余未完成数量
  • 支持"清除已完成"批量操作
  • 数据通过 localStorage 持久化,页面刷新后完整恢复
⚙️ 技术要求
  • 纯 HTML / CSS / 原生 JavaScript,不引入框架与 UI 库
  • 动态列表使用事件委托,统一事件监听
  • 数据操作使用数组方法(map / filter / reduce / find)
  • 存储使用 JSON 序列化;读取时对损坏数据容错,回退为空数组
  • 用户输入通过 textContent 或转义输出,禁止直接 innerHTML 拼接(防 XSS)
  • 完成态使用 class 控制样式(划线 / 置灰),不用内联 style
✅ 验收标准
  • 刷新或关闭重开页面后,任务与完成状态完整保留
  • 三种筛选切换后,列表、计数、空状态均正确
  • 编辑态按 Esc 取消、回车保存
  • 空列表、空搜索结果有明确提示
  • 移动端(≤600px)可正常操作

🌤️ 天气卡片小工具

API / fetch
城市搜索 · 四态 UI · 单位切换 · 最近搜索
🎯 核心知识点:fetch / async-await / 错误处理
📋 功能要求
  • 城市名搜索,输入防抖(500ms)或回车触发
  • 展示:城市、实时温度、体感温度、天气状况、图标、湿度、风速、日出日落
  • 加载中显示骨架屏或 loading 指示
  • 错误状态区分:城市不存在(404)、网络失败、请求超时(5s),分别提示并支持重试
  • 最近搜索历史(最多 5 条),点击可再次查询,localStorage 持久化
  • 摄氏 / 华氏单位切换,切换后所有温度即时更新
  • 可选:navigator.geolocation 定位当前城市
⚙️ 技术要求
  • async/await + fetch 发起请求,统一封装请求函数
  • AbortController 实现请求超时取消与竞态保护(快速连续搜索时丢弃过期响应)
  • 温度、风速、时间戳等数据做格式化与字段容错,接口缺字段不崩溃
  • API Key 不直接暴露在源码,开发环境使用 .env 或代理;缺失时给出明确提示
  • loading / error / empty / success 四态分离,禁止状态混用
✅ 验收标准
  • 连续快速搜索不同城市,最终展示的始终是最后一次结果(无竞态错乱)
  • 搜索不存在的城市,给出"未找到该城市"提示而非空白
  • DevTools 离线模拟断网时,提示网络错误并给出重试
  • 切换单位后,温度与体感数据同步刷新
  • 搜索历史刷新后仍可点击查询

🛒 简易购物车系统

Redux / Pinia
商品列表 · 增删数量 · 库存校验 · 状态管理
🎯 核心知识点:状态管理 / 派生数据 / 持久化
📋 功能要求
  • 商品列表:图片、名称、价格、规格(可选)、库存标签;库存为 0 时禁用加入
  • 加入购物车,同一商品合并为一行,不出现重复条目
  • 购物车内:数量加减(上限为库存,下限为 1)、移除、单项小计
  • 顶部购物车图标显示总数量角标
  • 合计金额实时计算
  • 空购物车提示与"去逛逛"入口
  • 可选:优惠码(折扣 / 满减)、模拟结算流程
⚙️ 技术要求
  • 状态管理:React 用 Redux Toolkit,Vue 用 Pinia,数据流集中在 store
  • 购物车使用持久化插件(Redux-persist / pinia-plugin-persistedstate),刷新不丢
  • 总价 / 总数量等派生数据使用 selector / getter,禁止在组件中重复计算
  • 购物车变更必须走 action,遵循不可变更新,禁止直接篡改 state
  • 加入与增减数量均校验库存边界,数量不可为负
  • 通过 Redux DevTools / Vue Devtools 观察状态变化
✅ 验收标准
  • 数量减到 1 时减号禁用,加到库存上限时加号禁用
  • 商品库存为 0 时按钮禁用并显示缺货说明
  • 删除 / 增减数量后,总价与角标同步正确
  • 刷新后购物车数据保留
  • 同一商品重复加入不产生重复行

💬 聊天界面 (仿微信)

CSS Modules
消息列表 · 气泡样式 · 自动滚动 · 模拟回复
🎯 核心知识点:列表渲染 / 滚动控制 / 样式打磨
📋 功能要求
  • 消息列表:左右气泡区分自己 / 对方,包含头像、昵称、内容
  • 时间戳:每条消息显示,或按日期 / 时段分组
  • 输入框回车发送;空内容与纯空白拦截;发送后自动清空
  • 模拟回复:对方在 1~2 秒后随机回复预设话术,可选显示"正在输入"
  • 自动滚动:新消息发送 / 收到时滚动到底;用户上翻时不强制拉回(可选)
  • 可选:长按 / 悬停删除消息、表情选择器、未读数角标
⚙️ 技术要求
  • 样式隔离:CSS Modules 或 Vue scoped,气泡样式互不污染
  • 中文输入法兼容:监听 compositionstart / compositionend,组合期间不触发发送
  • 自动滚动使用 scrollIntoView 或 scrollTop,并判断是否贴近底部再滚动
  • 消息区性能:初始渲染 20 条,长列表可用虚拟滚动(可选)
  • 气泡入场动画(transform / opacity)
  • 消息数据使用 mock 数组管理,每条消息有唯一 id,渲染 key 稳定
✅ 验收标准
  • 连续发送 50 条消息后滚动流畅,无重复渲染与控制台报错
  • 中文输入拼音过程中回车不误发送
  • 长文本消息正常换行,不撑破布局
  • 贴近底部自动跟随,上翻历史时不被强制拉回
  • 若实现了会话持久化,刷新后记录保留
